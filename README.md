# Payal Bargal — Animated Portfolio

## Run
Open `index.html` in Chrome/Edge.

## Customize
- Update project descriptions/links in `index.html`.
- Replace the GitHub/LeetCode/HackerRank links if needed.
- Add your resume PDF as `resume.pdf` and add a Resume button if desired.
- Main styling is in `style.css`.
- Animations/interactions are in `script.js`.

The design is responsive and uses a lavender/pink dark-glass aesthetic with scroll reveal, floating hero card, animated progress bar, hover effects and mobile navigation.
